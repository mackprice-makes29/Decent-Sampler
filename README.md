## 📖 About

Decent Sampler is developed by Decent Samples and ships as a VST3, VST2 and standalone application for Windows. It reads the DSLIB library format, supports multi layer velocity mapping, round robin playback, built in reverb and delay, ADSR envelopes, external sample folders and a background image plus interface layout described in a simple XML file. Recent builds add ASIO and WASAPI audio device selection, MIDI learn for hardware controllers, a resizable interface and improved memory handling when loading larger libraries.

If you came looking for a Decent Sampler download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. It is a community reference page that collects the practical details a Windows user needs before and after installing the plugin.

**Good for:** home studio producers · film and game composers · sound designers · keyboard and MIDI controller players · beginners learning sample libraries · teachers building classroom instrument setups · anyone opening DSLIB libraries in a DAW

## 🔑 Features

| | |
|---|---|
| 🎛️ **DSLIB library support** | Loads Decent Sampler format libraries with samples, mappings and interface layout defined in one folder. |
| 🎚️ **Multi layer velocity mapping** | Assign different sample layers per velocity range for realistic dynamics on pianos, drums and pads. |
| 🔁 **Round robin playback** | Cycles alternate samples on repeated notes to avoid the machine gun effect on fast passages. |
| 🎹 **MIDI learn and controller mapping** | Bind knobs, faders and sustain pedals from a hardware controller directly to plugin parameters. |
| 🌊 **Built in effects** | Reverb, delay, filter, ADSR envelope and volume controls available without an extra plugin chain. |
| 🔊 **ASIO and WASAPI output** | Choose a low latency driver for live playing or a shared mode driver for desktop listening. |
| 🖼️ **Custom instrument interface** | Library authors define background art, knob positions and controls in the accompanying XML file. |
| 🧩 **VST3, VST2 and standalone** | Use it inside a DAW host or launch it as its own window for practice and quick auditioning. |
| 💾 **External sample folders** | Point libraries at sample content stored on another drive to keep the main install folder lean. |

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Plugin not visible in the DAW | Rescan plugin folders in the DAW settings and confirm the VST3 path matches the install location. |
| No sound when playing notes | Check the audio device in settings, verify the MIDI input is selected and confirm the library loaded without missing samples. |
| Crackling or dropouts during playback | Raise the buffer size in the audio settings or switch to an ASIO driver for lower latency. |
| Library loads but shows empty interface | Confirm the DSLIB folder contains the XML file, the samples subfolder and the background image in the expected layout. |
| Installer stops partway through | Close other audio applications, temporarily pause cloud sync on the target folder and run setup again. |
| Interface text or controls look tiny | Use the interface scaling option in settings or adjust Windows display scaling for the app. |
